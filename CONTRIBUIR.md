# Cómo subir tu parte

No necesitas saber programar. Todo se puede hacer desde la página de GitHub.

## Desde la página (lo más fácil)

1. Entra al repositorio y abre la carpeta donde va tu archivo (por ejemplo
   `entregas/2026-10-22-cuestionario-mvp`).
2. Clic en **Add file → Upload files** y arrastra tu archivo.
   Si es texto, también puedes usar **Add file → Create new file**.
3. Abajo, en *Commit changes*:
   - Escribe qué subiste, por ejemplo: `Criterio de validación del cuestionario`.
   - Elige **Create a new branch** y ponle tu nombre y la tarea: `fatima/cuestionario`.
4. Clic en **Propose changes** y luego en **Create pull request**.
5. Espera el resultado del pipeline (palomita verde o tache rojo) y pide revisión a Oscar.

## Reglas

- Nombres de archivo en minúsculas y sin espacios: `criterio-validacion.md`,
  no `Criterio Validacion FINAL (2).md`. El pipeline lo revisa.
- Cada carpeta de `entregas/` tiene su `README.md`: no lo borres.
- No subas datos personales de nadie (teléfonos, correos, cuentas): el repositorio es público.
- Si algo sale en rojo y no sabes por qué, comenta en tu Pull Request y te ayudamos.
