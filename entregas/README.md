# Entregas de clase

Una carpeta por tarea de Classroom, con el formato `AAAA-MM-DD-nombre-corto`
(la fecha es la de entrega). Oscar crea la carpeta y el issue cuando la profesora
deja la tarea; cada carpeta tiene un `README.md` con lo que se pide, quién hace qué,
cómo hacerlo y el estado.

## Cómo cumplir con una entrega

1. Lee el `README.md` de la carpeta y busca tu nombre en "Quién hace qué".
2. Haz tu parte y súbela a esa carpeta con el nombre de archivo indicado.
3. Abre un Pull Request y escribe "Parte de #número" con el issue de la tarea.
4. Cuando todas las partes estén, el responsable de la entrega arma el documento
   final y lo sube a Classroom antes de la hora límite.
