# Pruebas de GymDesk

QA escribe aquí los **casos de prueba** y Calidad los usa para sus listas de
verificación. Se prueban con el instalador de *Releases*; no se necesita el código.

- Un archivo por módulo: `acceso.md`, `caja.md`, `socios.md`, `inventario.md`, `reportes.md`.
- Copia [plantilla-casos.md](plantilla-casos.md) para empezar uno nuevo.
- Si un caso falla, abre un issue con la plantilla **Reporte de error** y pon su ID (por ejemplo `CAJ-03`).

| Módulo | Prefijo | Archivo |
|---|---|---|
| Control de acceso | ACC | [acceso.md](acceso.md) |
| Caja y punto de venta | CAJ | por crear |
| Socios y membresías | SOC | por crear |
| Inventario | INV | por crear |
| Reportes | REP | por crear |
