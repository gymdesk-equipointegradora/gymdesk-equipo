# Libro de referencia

Todo el proyecto sigue el libro que usa la profesora:

> **Administración Profesional de Proyectos – La Guía**, Yamal Chamoun.
> Método Escala.

## Cómo conseguirlo

El libro tiene derechos de autor, así que **no se sube a este repositorio** (es
público). Pídele al Gerente del Proyecto (Oscar) el enlace a la carpeta privada del
equipo, o consíguelo en la biblioteca de la universidad o en librerías.

## Qué parte usar para cada documento

Busca en el índice del libro el nombre de la herramienta: el libro explica qué es,
para qué sirve y trae un ejemplo de cada una.

| Etapa del libro | Herramientas | Estado en el proyecto |
|---|---|---|
| Visualización | Mapa Mental de Expectativas, Charter | Charter hecho; mapa pendiente |
| Planeación: alcance y organización | Declaración del Alcance, WBS, Diagrama Organizacional, Matriz de Roles y Funciones | Hechos |
| Planeación: comunicación y control | Matriz de Comunicación, Calendario de Eventos, Estatus Semanal, Reporte Mensual | Hechos |
| Planeación: tiempo | Programa – Ruta Crítica | Pendiente |
| Planeación: costo | Estimados de Costos, Imprevistos y Contingencias, Presupuesto Base, Programa de Erogaciones | Pendientes |
| Planeación: calidad | Análisis de Precedentes (Benchmarking), Diagrama Causa-Efecto con Lista de Verificación | Hechos |
| Planeación: riesgos | Mapa de Riesgos, Matriz de Administración de Riesgos | Pendientes |
| Planeación: abastecimientos | Matriz de Abastecimientos | Hecha |
| Planeación: cambios y aprendizaje | Control de Cambios, Lecciones Aprendidas | Pendientes |
| Ejecución, control y cierre | Listas de Calidad, Cotizaciones, Reportes de Avance, Reporte Final, Acta de Entrega | Pendientes |

Quién hace cada pendiente: [pendientes.md](pendientes.md).

¿Dudas sobre el libro? Consulta con el Gerente del Proyecto.
